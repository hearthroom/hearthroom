# Official blog languages

Each article has one content language. When publishing several language versions of the
same article, end each slug with its language code in lowercase: `-zh-hant`, `-zh-hans`,
`-en`, `-ja`, or `-ko` (for example, `card-community-play-zh-hans`). The article's language
setting must match that version. Lists, pinned posts, recommendations, and Atom feeds show
the reader's language. Traditional and Simplified Chinese lists also retain older articles
in the other Chinese language when the slug has none of these language suffixes. English,
Japanese, and Korean lists use their own language only. Articles keep their original
language and canonical URL; this does not translate their contents or link translations.
