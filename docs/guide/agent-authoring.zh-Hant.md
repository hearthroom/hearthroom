## 能交給 AI Agent 的事

AI Agent 照官方寫卡技能工作：先問清楚你要什麼，把卡寫成資料夾、推成試玩卡，自己檢查和試玩，再告訴你哪裡還能更好。每一項都附一句可以直接對它說的話。

### 從一個點子寫出整張卡

> 「寫一張修仙文的卡：我是被逐出宗門的廢柴，師姐偷偷幫我，要有修為和好感度兩個狀態，先做成試玩卡。」

只有模糊的想法也可以，它會先陪你把設定、人物、關係和開場白想清楚再動手。

### 修好一張現有的卡

> 「匯入這張 SillyTavern 卡，告訴我為什麼聊三輪就沒話說，然後修掉。」

SillyTavern 的 PNG、JSON、CHARX 和魅魔島三件套都能直接匯入。

### 做狀態欄、主題或整頁介面

> 「加一個顯示好感度和所在地點的狀態欄，渲染開場白給我看。」

需要畫面時，它用工具包自己的沙盒套件（模型寫的狀態區塊畫成面板、選項鈕、主題），用 `hearthroom card check` 檢查資料夾，再用 `hearthroom card preview` 與 `card render` 看結果。

聊天頁本身是開源的（`hearthroom/moonstage`，本站的 `stage` 子模組）：skills 的沙盒契約由它的 `src/sandbox/` 生成，文件沒寫到的事，平台事實頁列出該讀哪些檔案。

### 試玩並找出問題

> 「用第二個開場白玩兩輪，告訴我玩家會在哪裡失去興趣。」

### 上架前的檢查

> 「檢查這張卡能不能送審，列出還要修的地方。」

## AI Agent 怎麼寫卡

1. **寫成資料夾**：長文是 Markdown 檔，世界書、規則和圖片各有自己的檔案，你也能打開來看或自己改。
2. **推成試玩卡**：只有你看得到，最後一次更新後 3 天過期，同時最多 5 張。
3. **檢查與渲染**：照平台規則檢查字數與內容，把開場白套上規則渲染出來，確認狀態欄和版面正確。
4. **試玩**：真的跟角色聊一輪，看回覆撐不撐得住、玩家接不接得下去。
5. **修改**：照結果改，再推、再試，直到你滿意。
6. **留下來**：滿意之後存成正式的私人卡，出現在「我的卡片」。送審和公開由你在網站上決定。

## 讓 AI Agent 寫得更好

- **說清楚想要的玩法**：陪伴、劇情、遊戲或角色生成器，寫法完全不同。
- **給它素材**：二創就說清楚是哪部作品的哪個角色，再加上你的設定和喜歡的卡。
- **要它試玩**：只寫不玩的卡，最常見的問題是聊幾輪就沒戲；請它先玩兩輪再交給你。
- **一次改一件事**：「開場白太長、她太快示好」比「整體再好一點」有效。
- **看它的報告**：每次推送後的檢查結果和渲染畫面，比它自己的總結可靠。

## 點數與界線

- 起草、推送、檢查和渲染都不花點數。
- 試玩一輪會用到你的點數，AI Agent 會先問過你。
- 它只動試玩卡和你自己的私人卡，不會替你送審或公開。
