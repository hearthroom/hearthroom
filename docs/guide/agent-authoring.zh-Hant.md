## 先做出第一版能聊的卡

照上方的步驟裝好設定後，不用先研究欄位格式，直接把你想做的角色或手邊的舊卡交給 Agent，幾分鐘內就能拿到一條私人試玩連結。Agent 會依官方寫卡技能工作，只有在不同理解會做出完全不同的卡片時才會停下來問你。

如果你在寫卡過程遇到下面這些狀況，也可以直接跳到對應段落：

- 想法還很模糊、不知道玩什麼：[想法還很模糊時，先請它列幾個方向讓你挑](#想法還很模糊時先請它列幾個方向讓你挑)
- 寫出來的卡跟市面上的套路太像：[講出玩家現在的處境，別只丟一個題材名稱](#講出玩家現在的處境別只丟一個題材名稱)、[用一句角色會講的話，代替一整排形容詞](#用一句角色會講的話代替一整排形容詞)
- 有原作、自己的筆記或喜歡的參考卡：[做二創或手邊有設定稿時，直接把素材丟給它](#做二創或手邊有設定稿時直接把素材丟給它)
- 繁簡用語、詞彙或對玩家的稱呼不對：[一開始講明繁簡用語與稱呼習慣](#一開始講明繁簡用語與稱呼習慣)
- 狀態欄與選項按鈕蓋過故事本身：[說清楚畫面要純故事還是數值玩法，點名不要哪些預設面板](#說清楚畫面要純故事還是數值玩法點名不要哪些預設面板)
- Agent 每做一小步就停下來問你：[寫清楚完成的標準，以及它能自己決定的範圍](#寫清楚完成的標準以及它能自己決定的範圍)
- 說測過了，但實際聊三輪就接不下去：[請 Agent 用不同模型與開場白跑十輪實測，並看工作紀錄](#請-agent-用不同模型與開場白跑十輪實測並看工作紀錄)
- 改完反而變差，或改到沒叫它動的地方：[講你玩到的現象，不要替它指定改哪一段](#講你玩到的現象不要替它指定改哪一段)、[一個版本只改一件事](#一個版本只改一件事)
- 只是問個意見，檔案卻被直接改掉：[只想聽分析、還不要改檔案時先講明](#只想聽分析還不要改檔案時先講明)
- 新開對話視窗想接著上次繼續做：[新開對話視窗，或跟網頁編輯器一起改](#新開對話視窗或跟網頁編輯器一起改)

### 想法還很模糊時，先請它列幾個方向讓你挑

腦中只有一個題材（例如「末日」「修仙」「校園」）的時候，如果直接說「你看著辦」，做出來的多半是最常見的罐頭套路；但還沒看過方向就叫它寫完整張卡，不合意又得重來。可以先叫它別動手寫卡，只列幾個不同的玩法與關係讓你選：

> 我想做一張末日題材的卡，但還沒想好要玩什麼關係。你先別建卡，給我三個不同的方向，每個用一兩句話講清楚我是誰、跟角色卡在什麼局面裡，我挑一個你再寫。

### 講出玩家現在的處境，別只丟一個題材名稱

只講「寫一張好玩的女僕卡」，Agent 只能湊出最常見的設定跟開場。動筆前多交代兩件事：玩家在故事裡是什麼身分、兩個人之間卡著什麼沒說破的事。開始寫之前，Agent 會先跟你說這個題材一般都怎麼寫、這張卡打算怎麼避開老套路，覺得方向不對在這一步就能先改，不用等整張卡寫完：

> 幫我做一張老宅女僕卡。我是剛繼承這棟老洋房的遠房親戚，她是前屋主留下的管家，屋子裡見不得光的事只有她清楚。設定成我慢慢拿到她的信任她才會把秘密講出來，但全部講完她就沒有理由繼續待在這裡了。動手前先跟我說一般女僕卡都怎麼寫、你這張打算怎麼弄得不一樣。

### 用一句角色會講的話，代替一整排形容詞

寫「個性傲嬌、嘴硬心軟、說話自然一點」，每個人想像出來的語氣都不一樣，Agent 也只能套大眾範本。直接寫一句她實際會開口說的台詞，句子的長短、禮貌程度跟話留幾分就全定下來了。提供對白樣本時，一句就夠，給到三句以上 Agent 反而會開始模仿句型，抓不到語氣：

> 她講話抓這句的感覺：「少爺，二樓盡頭那扇門的鑰匙，我想您現在還用不上。」全程客客氣氣的但話都不講滿，也不跟人多解釋。你先照這個口氣試寫三句不同場合的台詞給我看，對了再寫整張卡。

### 做二創或手邊有設定稿時，直接把素材丟給它

原作角色的細節、你自己寫過的設定筆記，或是別張你很喜歡的卡片，都不要叫 Agent 憑印象硬猜。像「幫我寫某某動畫裡那個冷淡學姊」這種講法很容易走樣，直接把設定檔附上去，講清楚哪些地方不能動、哪些地方要改。如果附了別張卡當參考，也要點明你想學的是它的開場節奏還是對話密度，免得連題材都被抄過去：

> 我要做《葬送的芙莉蓮》的費倫二創卡，角色筆記放在 `notes/fern.md`。她叫修塔爾克「修塔爾克大人」、生氣會鼓著臉不理人這兩點一定要留著，時間點改到一級魔法使考試剛考完那幾天。另外桌面上那張 `sample.json` 是我很喜歡的一張日常卡，參考它開場白怎麼起頭就好，裡面的世界觀不用管。

### 一開始講明繁簡用語與稱呼習慣

「用中文寫」沒有指明繁體或簡體，也沒說要用台灣習慣詞彙還是其他地區的說法。連同角色怎麼叫玩家、要不要預設玩家名字，在第一句話順手講清楚，後面就不用逐欄重改：

> 整張卡用繁體中文跟台灣習慣用語，不要混進簡轉繁的詞。角色叫玩家「你」不用「您」，玩家名字直接留給玩家自己的設定，卡裡不要先幫玩家取名。

### 把別處的舊卡搬過來翻修

手邊如果有 SillyTavern 的 PNG、JSON、CHARX 卡，或是魅魔島（MMD）三件套、AI 風月、RiliAI 匯出的檔案，直接把路徑丟給 Agent 就能匯入。除了轉好格式、列出哪些舊平台欄位需要調整之外，也很適合拿來修「聊幾句就詞窮」的老毛病：

> 幫我把下載資料夾裡那張 `silverwolf.png` 匯進來。現在這張卡跟她聊不到四輪，她就只會重複問我要不要打電動，你幫我看一下是設定還開場白寫死了，修好之後推成試玩卡給我試。

### Agent 在背後幫你跑的流程

你開口之後，Agent 會在你的電腦與站上依序完成這幾步：

1. **寫成本機資料夾**：人設與開場白是 Markdown 檔，世界書、顯示規則與圖片各自獨立成檔，你隨時可以直接打開來看或自己手改。
2. **上傳成私人試玩卡**：預設推到只有你自己看得到的試玩卡，最後一次更新滿 3 天後自動過期，一個帳號同時最多保留 5 張（滿了可覆蓋最舊的一張）。
3. **檢查字數與渲染畫面**：照平台規則檢查各欄字數與語法，並把開場白套上顯示規則跑一次，確認面板和排版沒有壞掉。
4. **實際試玩**：送出訊息跟角色聊幾輪，確認角色接得住話、劇情推得動。
5. **來回修改**：根據檢查和試玩結果調整檔案，再推上去重測。
6. **存成正式卡**：等你點頭說要留存，才存進「我的卡片」；要不要送審公開，完全由你自己決定。

## 加上世界書、數值面板、沙箱畫面與配圖

第一版聊順之後，如果想讓長篇劇情不失憶、精確記住好感度與背包道具，或是把對話頁改成視覺小說那樣的專屬介面，可以直接請 Agent 幫卡片加上平台的進階功能。

### 用世界書裝下龐大世界觀，還不會提前劇透

人物關係、地名、陣營規矩越寫越多時，全塞進人設會佔掉每一輪的對話額度。請 Agent 把這些設定拆進世界書（Lorebook）後，系統平時會依關鍵詞與對話語意自動挑出相關條目帶進對話；如果是後面章節才要揭曉的真相，還可以請 Agent 把那幾條的「語意召回」關掉，改成只有玩家真的問到關鍵詞時才觸發：

> 這張偵探卡的七個嫌疑人背景跟宅邸平面圖太長了，幫我拆進世界書。管家真正的死因跟密道位置先幫我關掉語意召回，只有玩家搜到「懷錶」或「地下室」的時候才讓 AI 看到，免得前兩輪就被說溜嘴。

### 說清楚畫面要純故事還是數值玩法，點名不要哪些預設面板

卡片的畫面大致分兩種：一種以閱讀故事為主、畫面越乾淨越好；另一種則是養成、求生或跑團，數值跟選項就是玩法本身。如果你沒特別交代，Agent 常會照一般熱門卡的習慣，幫你加上好感度條、每輪結尾固定給兩到四個選項按鈕，或把角色心情全部量化成數字。只說「不要太像 AI」它猜不出你想拿掉哪一塊，直接點名要什麼、不要什麼才有用。另外，就算完全不寫顯示規則，聊天頁也會自動把回覆結尾的 `[status]`／`[choices]` 區塊畫成面板與按鈕，所以「需不需要畫面面板」跟「需不需要寫顯示規則」是兩件分開的事。

如果只是想做乾淨的陪伴或劇情卡，可以這樣說：

> 這張是日常陪伴卡，我想安安靜靜看對話就好，就算只看純文字也要順。好感度條、每輪結尾的選項按鈕跟把心情換成數字那些都不用加，只要在回覆最底下留一行寫她現在人在哪、幾點鐘就好。

反過來，做求生、經營或養成卡時，每一項顯示出來的狀態都應該要有玩家能採取的行動去改變它；如果數值不能讓模型憑印象亂湊（像是金錢、剩餘糧食、道具欄），還能請 Agent 啟用原生的**卡片變數**，每輪自動加減，連玩家按重新生成或退回上一句時，數值都會跟著準確回退：

> 這張孤島求生卡幫我開卡片變數，狀態只放淡水、乾糧、體力這三樣，每一樣都要有對應的行動可以增減，玩家動不了的裝飾數字都不要放。每回合底下附兩三個行動選項，面板簡單好讀就好。

### 獨立沙箱畫面、開場網頁與跨玩家互動

需要自訂整頁樣式、深淺色主題或釘選列時，新卡預設跑在獨立的沙箱聊天頁上。Agent 會用寫卡技能內建的沙箱套件（把模型輸出的狀態區塊畫成面板、選項鈕、抽屜、釘選列與深淺色主題），先在本機跑 `hearthroom card check` 檢查規則與標記有沒有對上，再用 `hearthroom card preview` 與 `card render` 載入站上真實的沙箱殼，直接截出手機與桌機、深色與淺色畫面檢查字體大小與排版。聊天頁本身也是開源的（`hearthroom/moonstage`，本站的 `stage` 子模組）：技能的沙箱契約由它的 `src/sandbox/` 生成，文件沒寫到的細節，平台事實頁也列出了 Agent 應該讀取的檔案。

除了改配色與面板，你還可以叫 Agent 做新對話最上方的**開場網頁**（像遊戲標題畫面一樣選出身、挑路線）、做多線存讀檔選單，甚至接上**全服玩家共用的投票與共鬥計數器**，或是**帶情境碼的分享連結**（朋友點開你的連結就能接著你的選擇玩）：

> 這張地下偶像養成卡我想做成深色霓虹風。新開對話最上面先放一頁開場網頁，讓玩家選自己是「剛接手的小經紀人」還是「退居幕後的前製作人」再開局。另外幫我加一個全服玩家共用的應援計數器，做完後把手機跟電腦的深淺色預覽截圖給我看。

### 拿同一張立繪當參考，生出封面、橫幅與表情差分

手上只有一張角色立繪、還缺寬螢幕橫幅或不同表情的插圖時，可以請 Agent 呼叫站上的生圖模型，直接把現有立繪當成參考圖傳進去，讓新圖維持同一張臉、髮型與服裝。生圖會花費儲值積分（被內容規則擋下或生成失敗不扣點），Agent 動手前會先查好價格問你：

> 拿現在這張直式立繪當參考圖，幫我生一張 16:9 的雨夜街頭橫式背景，再多生兩張她「冷笑」跟「別過頭臉紅」的半身差分放進卡片素材裡。先查一下模型價格跟總共要花多少儲值積分，跟我確認後再生。

## 讓 Agent 一次做到位，不用每一步停下來問你

如果你發現 Agent 每寫一個檔案就停下來問「這樣可以嗎」，通常是因為它還不確定做到哪裡算完成，也不敢自己決定要不要花積分測試。

### 寫清楚完成的標準，以及它能自己決定的範圍

把指令寫成「先寫設定給我看，再寫人設，再寫開場白」，Agent 就會每做完一小步都停下來等你點頭。想讓它一口氣把整套流程跑完，只要交代清楚最後要交出什麼結果、試玩花費在多少積分以內可以自己安排，以及哪些大事才需要回來問你：

> 這張卡你直接一路做到推成試玩卡、自己試聊過十輪，再回來告訴我哪裡還不夠自然。中間改檔跟重推試玩卡都不用問我，試玩花費在 50 積分以內你自己安排，超過再說。除非要存成正式卡、送審公開，或是遇到會讓整張卡變成不同故事的大改動，其他細節你直接決定就好。

如果你反而希望它多跟你討論、不要自己做太多決定，把最後那句授權拿掉就行。

### 送出指令前，先看一眼這五件事

每次要讓 Agent 開新卡或改舊卡前，可以快速掃一遍：

- 開新卡時，除了題材名稱，也要寫出玩家是什麼身分、正遇到什麼狀況。
- 想固定角色的說話方式時，直接給一兩句台詞當樣本，少用抽象的個性形容詞。
- 先講好畫面要純文字閱讀還是帶數值與選項，不想要的預設面板直接點名拿掉。
- 交代清楚做到哪一步算完成，以及多少積分以內的試玩可以直接跑。
- 修改既有卡片時，一則訊息只集中處理一個問題。

## 試玩之後怎麼改語氣、修卡關與接續進度

卡片聊個兩三輪通常看不出毛病，真正的問題多半出現在十輪之後，像是角色突然太快示好、台詞開始重複，或是改了一個地方卻把原本寫好的段落弄壞。

### 請 Agent 用不同模型與開場白跑十輪實測，並看工作紀錄

只問一句「你測過了嗎」，拿到的回答通常都是「測過了」，但預設試聊兩輪只能確定開場白沒壞。一張卡耐不耐玩要跑到十輪以後才見真章，而且比較弱的模型最容易先露出破綻。你可以指定用哪個備選開場白、分別拿小模型跟高階模型跑 10 到 20 輪（實際對話會扣積分，Agent 會先報價）。跑完除了聽它口頭報告，也可以直接打開卡片資料夾裡的 `README.md`。那是 Agent 留在本機的工作筆記，裡面會記下每一版改了什麼、為什麼放棄某個寫法，以及測試抓到的對話證據（這個檔案不會上傳到伺服器）：

> 拿第二個備選開場白，分別用一個便宜的小模型跟一個高階模型各開新對話跑 15 輪。幫我看大概聊到第幾輪會開始鬼打牆或接不下去、問題出在哪，把測出來的結果記進 `README.md`，開跑前先跟我說大概要花多少積分。

### 講你玩到的現象，不要替它指定改哪一段

自己試玩覺得不對勁時，如果直接下令「把人設第二段砍短一點」，往往治標不治本。你在畫面上看到的是結果，真正害角色崩掉的原因常常藏在開場白示範、對話示例或輸出格式裡。直接把你玩到的現象講出來，請它去查根因，並要求改完後用同一組對話跟上一版比對給你看：

> 我剛才自己玩，才聊到第三輪她就主動貼上來告白了，我希望慢熱很多，前十輪都還在互相試探。你先找一下是什麼地方害她這麼快暈船，改好之後用我剛才那幾句話重跑一次，跟改之前的回覆對照給我看。

### 一個版本只改一件事

把「開場白太長、她太快示好、世界觀太薄、順便幫配角換個名字」塞在同一句話裡，Agent 一次動太多檔案，改壞了根本分不清是哪一刀出的問題，也很容易順手改掉你原本滿意的段落。每次只指定修一個問題，其他它順帶看到的毛病請它先列出來別動：

> 這一版先修她太快暈船這件事就好，其他你看到的毛病先列出來別動檔案。改完跟我講你動了哪幾個檔、各改了什麼。

### 只想聽分析、還不要改檔案時先講明

當你問「這張卡是不是改成多路線會比較好玩？」，Agent 有時分不出你只是在討論，還是已經要它動手重寫，常常問完就直接開始改檔案。如果只是想拿主意，第一句話先叫它別動檔案：

> 先不要改任何檔案。你覺得這張卡現在走單線慢熱陪伴比較穩，還是拆成三個篇章比較耐玩？跟我講兩邊各自的優缺點就好，等我決定再動手。

### 新開對話視窗，或跟網頁編輯器一起改

關掉終端機重開一個新對話時，Agent 沒有上一次的聊天記憶，只說「繼續改昨天那張卡」它就得從頭瞎猜。請它先讀卡片資料夾裡的 `README.md`，就能馬上接回上次的進度：

> 接著改 `cards/night-diner` 這張卡。你先讀裡面的 `README.md`，跟我確認一下上一版改到哪裡、還剩哪些待辦事項，確認完再往下做。

如果你中途自己開網頁編輯器改過文字或世界書，開工前跟它說一聲「先從線上拉最新版下來」；如果你還在網頁上邊改人設、只想讓 Agent 幫你補幾條世界書，它也可以用單條世界書指令只更新那幾條設定，遇到版本衝突會自動停下來，不會把你在網頁剛存好的內容蓋掉。

## 存成正式卡、私下分享與送審公開

試玩卡在最後一次更新滿 3 天後就會自動過期，確定要留住這張卡、傳連結給朋友玩，或是上架到首頁榜單拿積分返點時，再請 Agent 幫你存成正式卡或檢查送審條件。

### 存成正式卡與三種公開範圍

跟 Agent 說「幫我把這張試玩卡存成正式卡」，卡片就會進到你的「我的卡片」清單裡，不會再過期。新建正式卡預設的公開範圍是「**有連結的人**」：不會出現在首頁榜單與搜尋結果裡，也不用先送審，但只要你把連結傳給朋友，對方就能直接打開玩最新存檔。如果你只想留給自己玩，隨時可以請它設成「**僅自己**」。

### 送審上架前的檢查

想把卡片設成「**公開**」（排進首頁與搜尋、累積熱度參加日／週／月榜拿獎金，並在其他玩家來聊時分到積分返點），卡片需要符合三個條件：至少選一個官方的分類或玩法標籤、「角色設定」加上「已啟用的世界書常駐條目」合計超過 3,000 個有效字（中英文字母與數字都按字元算，不含標點空白、開場白、對話示例與非常駐條目），以及填妥台灣遊戲軟體分級問卷。送出前可以先叫 Agent 全部核對一遍：

> 先不要送審，幫我檢查這張卡現在能不能公開上架，看有效字數、分類標籤跟欄位有沒有缺，把還要補的地方列給我。

卡片公開之後，你還是可以繼續叫 Agent 修改。後續推送只會更新你自己的草稿（你可以用草稿連結先試玩），線上玩家玩的仍是已經過審的版本，直到你再次送審通過為止；更新送審預設不會打擾玩家，只有你主動要求發更新通知並寫上更新說明時，才會在過審後通知收藏卡片與追蹤你的人（每張卡每 3 天最多通知一次）。

### 積分與安全界線

- 起草、修改檔案、本機規則檢查、沙箱畫面預覽、渲染開場白與上傳卡片，全部不消耗網站積分。
- 只有「實際送訊息跟角色試聊」與「呼叫模型生成圖片」會消耗積分（生圖僅使用儲值積分），這兩個指令都要帶上扣點參數才會執行，Agent 動手前一定會先徵求你的同意。
- Agent 只會修改試玩卡與你交給它處理的卡片；除非你開口要求，否則它不會自己替你送審、發更新通知或把卡片改成公開。
