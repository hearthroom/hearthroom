## 先做出第一版能聊的卡

照上面的步骤装好环境后，不用先研究字段格式，直接把你想做的角色或手头的旧卡交给 Agent，几分钟内就能拿到一条私人试玩链接。Agent 会按官方写卡技能工作，只有在不同理解会做出完全不同的卡片时才会停下来问你。

如果你在写卡过程中遇到下面这些情况，也可以直接跳到对应小节：

- 想法还很模糊、不知道玩什么：[想法还很模糊时，先让它列几个方向给你挑](#想法还很模糊时先让它列几个方向给你挑)
- 写出来的卡跟市面上的套路太像：[讲出玩家现在的处境，别只丢一个题材名](#讲出玩家现在的处境别只丢一个题材名)、[用一句角色会说的话，代替一排形容词](#用一句角色会说的话代替一排形容词)
- 有原作、自己的设定稿或喜欢的参考卡：[做同人或手头有设定稿时，直接把素材丢给它](#做同人或手头有设定稿时直接把素材丢给它)
- 简繁用词、习惯表达或对玩家的称呼不对：[一开始讲明简繁用词与称呼习惯](#一开始讲明简繁用词与称呼习惯)
- 状态栏和选项按钮盖过了故事本身：[说清楚画面要纯故事还是数值玩法，点名不要哪些默认面板](#说清楚画面要纯故事还是数值玩法点名不要哪些默认面板)
- Agent 每做一小步就停下来问你：[写清楚完成的标志，以及它能自己拍板的范围](#写清楚完成的标志以及它能自己拍板的范围)
- 说测过了，但实际聊三轮就接不下去：[让 Agent 用不同模型和开场白跑十轮实测，并看工作记录](#让-agent-用不同模型和开场白跑十轮实测并看工作记录)
- 改完反而更差，或动了没让它改的地方：[只报你玩到的现象，别替它指定改哪一段](#只报你玩到的现象别替它指定改哪一段)、[一个版本只改一件事](#一个版本只改一件事)
- 只是问个主意，文件却被直接改了：[只想听分析、还不要改文件时先讲明](#只想听分析还不要改文件时先讲明)
- 新开对话窗口想接着上次继续做：[新开对话窗口，或跟网页编辑器一起改](#新开对话窗口或跟网页编辑器一起改)

### 想法还很模糊时，先让它列几个方向给你挑

脑子里只有一个题材（比如“末日”“修仙”“校园”）的时候，如果直接说“你看着办”，拿回来的多半是最常见的套路；但还没看准方向就让它写完整张卡，不满意又得推倒重来。可以先让它别动手建卡，只给几个不同的玩法和人物关系让你选：

> 我想做一张末日题材的卡，但还没想好具体玩什么关系。你先别建卡，给我三个不同的方向，每个用一两句话讲清楚我是谁、跟角色卡在什么局面里，我挑一个你再写。

### 讲出玩家现在的处境，别只丢一个题材名

只说一句“写一张好玩的女仆卡”，Agent 只能拼出最常规的设定和开场。动笔前多交代两件事：玩家在故事里是什么身份、两个人之间卡着什么没挑明的事。开始写之前，Agent 也会先跟你说这个题材常见的一般写法是什么、这张卡打算怎么避开老套路，觉得不对味在这一步就能改方向，不必等整张卡写完：

> 帮我做一张老宅女仆卡。我是刚继承这栋老洋房的远房亲戚，她是前屋主留下的管家，宅子里见不得光的事只有她清楚。设定成我慢慢取得她的信任她才会把秘密一件件抖出来，但全讲完她也就没有理由继续留在这儿了。动手前先跟我说一般女仆卡都怎么写、你这张打算怎么弄得不一样。

### 用一句角色会说的话，代替一排形容词

写“性格傲娇、嘴硬心软、说话自然一点”，每个人脑补出来的语气都不一样，Agent 也只能套大众模板。直接写一句她真会开口说的台词，句子的长短、客气程度和话留几分就全定住了。提供台词样本时，一句就够，给到三句以上 Agent 反而会开始照抄句式，抓不到语气：

> 她说话抓这句的感觉：“少爷，二楼尽头那扇门的钥匙，我想您现在还用不上。”全程客客气气的但话都不说满，也不跟人多解释。你先照这个口气试写三句不同场合的台词给我看，对了再写整张卡。

### 做同人或手头有设定稿时，直接把素材丢给它

原作角色的细节、你自己攒的设定笔记，或者你很喜欢的其他卡片，都别让 Agent 凭印象硬猜。像“帮我写某某动画里那个冷淡学姐”这种说法很容易走样，直接把设定文件附上，讲清楚哪些必须保留、哪些要改。如果附了喜欢的卡当参考，也要点明你想学的是开场的切入方式还是对话密度，免得连题材一块儿模仿过去：

> 我要做《葬送的芙莉莲》的菲伦同人卡，整理好的角色笔记放在 `notes/fern.md`。她叫休塔尔克“休塔尔克大人”、生气会鼓着脸不理人这两点一定要留着，时间线改到一级魔法使考试刚考完那几天。另外桌面上那张 `sample.json` 是我很喜欢的一张日常卡，参考它开场白怎么起头就好，里面的世界观不用管。

### 一开始讲明简繁用词与称呼习惯

只说“用中文写”，Agent 不知道你要简体还是繁体，也不知道该用哪边的日常词汇。连同角色怎么称呼玩家、要不要预设玩家名字，在第一句话里顺手交代清楚，省得写完再逐栏返工：

> 整张卡用简体中文和日常口语，别混繁体字或翻译腔。角色叫玩家“你”不用“您”，玩家名字直接留给玩家自己的设定，卡里不要先帮玩家起名。

### 把别处的旧卡搬过来翻修

手头如果有 SillyTavern 的 PNG、JSON、CHARX 卡，或者魅魔岛（MMD）三件套、AI 风月、RiliAI 导出的文件，直接把路径丢给 Agent 就能导入。除了转好格式、列出哪些旧平台字段需要调整之外，也很适合拿来修“聊几轮就词穷”的老毛病：

> 帮我把下载文件夹里那张 `silverwolf.png` 导进来。现在这张卡跟她聊不到四轮，她就只会翻来覆去问我要不要打游戏，你帮我看下是设定还是开场白写死了，修好之后推成试玩卡给我试。

### Agent 在背后帮你跑的流程

你开口之后，Agent 会在本地和平台上依次跑完这几步：

1. **写成本地文件夹**：人设与开场白是 Markdown 文件，世界书、显示规则与图片各自存成独立文件，你随时可以直接打开查看或自己动手改。
2. **上传成私人试玩卡**：默认推到只有你自己看得到的试玩卡，最后一次更新满 3 天后自动过期，一个账号同时最多保留 5 张（满了可覆盖最早的一张）。
3. **检查字数与渲染画面**：按平台规则检查各栏字数与语法，并把开场白套上显示规则渲染一遍，确认面板和排版没坏。
4. **实际试玩**：发消息跟角色聊几轮，确认角色接得住话、剧情推得走。
5. **来回修改**：根据检查和试玩结果调整文件，再推上去重测。
6. **存成正式卡**：等你点头说要留下来，才存进“我的卡片”；要不要送审公开，完全由你自己决定。

## 加上世界书、数值面板、沙箱画面与配图

第一版聊顺之后，如果想让长篇剧情不失忆、准确记住好感度与背包道具，或者把聊天页改成视觉小说那样的专属界面，可以直接让 Agent 帮卡片加上平台的进阶功能。

### 用世界书装下庞大设定，还不会提前剧透

人物关系、地名、阵营规矩越写越多时，全塞进人设会占掉每一轮的对话空间。让 Agent 把这些设定拆进世界书（Lorebook）后，系统平时会按关键词和对话语义自动挑出相关条目带进对话；如果是后面章节才揭晓的真相，还可以让 Agent 把那几条的“语义召回”关掉，改成只有玩家真的提到关键词时才触发：

> 这张侦探卡的七个嫌疑人背景和庄园平面图太长了，帮我拆进世界书。管家真正的死因和密道位置先帮我关掉语义召回，只有玩家搜到“怀表”或“地下室”的时候才让 AI 看到，省得前两轮就说漏嘴。

### 说清楚画面要纯故事还是数值玩法，点名不要哪些默认面板

卡片的画面大致分两种：一种以读故事为主、界面越干净越好；另一种是养成、求生或跑团，数值和选项本身就是核心玩法。如果你没特别交代，Agent 常会按热门卡的习惯，默认给你加上好感度条、每轮结尾固定挂两到四个选项按钮，或把角色情绪全变成数字。只说“别太像 AI”它猜不出你想砍哪块，直接点名要什么、不要什么才管用。另外，就算一条显示规则都不写，聊天页也会自动把回复末尾的 `[status]`／`[choices]` 区块画成面板和按钮，所以“需不需要画面面板”和“需不需要写显示规则”是两码事。

如果只是想做干净的陪伴或剧情卡，可以这样说：

> 这张是日常陪伴卡，我想安安静静看对话就好，就算只看纯文字也要顺畅。好感度条、每轮结尾的选项按钮还有把心情量化成数字那些都别加，只要在回复最底下留一行写她现在人在哪儿、几点钟就行。

反过来，做求生、经营或养成卡时，每一项显示出来的状态都应该有玩家能采取的行动去改变它；如果数值不能让模型凭印象乱算（比如金钱、剩余粮食、道具栏），还能让 Agent 启用原生的**卡片变量**，每轮自动加减，连玩家点重新生成或退回上一句时，数值都会跟着准确回退：

> 这张荒岛求生卡帮我开卡片变量，状态只放淡水、干粮、体力这三样，每一样都要有对应的玩家行动可以增减，玩家动不了的装饰数字都别放。每回合底下附两三个行动选项，面板简单好读就行。

### 独立沙箱画面、开场网页与跨玩家互动

需要自定义整页样式、深浅色主题或顶部固定栏时，新卡默认运行在独立的沙箱聊天页上。Agent 会用写卡技能自带的沙箱套件（把模型输出的状态区块画成面板、选项按钮、抽屉、固定栏与深浅色主题），先在本地跑 `hearthroom card check` 检查规则与标记有没有对上，再用 `hearthroom card preview` 和 `card render` 加载站上真实的沙箱壳，直接截出手机与电脑、深色与浅色画面检查字号和排版。聊天页本身也是开源的（`hearthroom/moonstage`，即本站的 `stage` 子模块）：技能里的沙箱规范直接由它的 `src/sandbox/` 生成；遇到文档没展开写的边界情况，技能自带的平台参考文档也列出了 Agent 该去查阅的源码文件。

除了改配色和面板，你还可以让 Agent 做新对话最上方的**开场网页**（像游戏标题页一样选出身、挑路线）、做多线存读档菜单，甚至接上**全服玩家共用的投票与共斗计数器**，或是**带情境码的分享链接**（朋友点开你的链接就能接着你的选择往下玩）：

> 这张地下偶像养成卡我想做成深色霓虹风。新开对话最上面先放一页开场网页，让玩家选自己是“刚接手的小经纪人”还是“退居幕后的前制作人”再开局。另外帮我加一个全服玩家共用的应援计数器，做完后把手机和电脑的深浅色预览截图给我看。

### 拿同一张立绘作参考，生出封面、横幅与表情差分

手头只有一张角色立绘、还缺宽屏横幅或不同表情的插图时，可以让 Agent 调用站上的生图模型，直接拿现有立绘当参考图传进去，让新图保持同一张脸、发型和服装。生图消耗充值积分（被内容规则拦下或生成失败不扣分），Agent 动手前会先查好价格问你：

> 拿现在这张竖版立绘当参考图，帮我生一张 16:9 的雨夜街头横版背景，再多生两张她“冷笑”和“偏过头脸红”的半身差分放进卡片素材里。先查一下模型价格和总共要花多少充值积分，跟我确认后再生成。

## 让 Agent 一次做到位，不用每一步停下来问你

如果你发现 Agent 每写一个文件就停下来问“这样可以吗”，通常是因为它不确定做到哪一步算收工，也不敢自作主张花积分测试。

### 写清楚完成的标志，以及它能自己拍板的范围

把指令写成“先写设定给我看，再写人设，再写开场白”，Agent 就会每做完一小步都停下来等你确认。想让它一口气把整套流程跑通，只需交代清楚最后要交出什么结果、试玩花费在多少积分以内可以自己安排，以及哪些大事才需要回来问你：

> 这张卡你直接一路做到推成试玩卡、自己试聊十轮，再回来告诉我哪里还不够自然。中间改文件和重推试玩卡都不用问我，试玩花费在 50 积分以内你自己安排，超过再说。除非要存成正式卡、送审公开，或者遇到会让整张卡变成另一个故事的大改动，其他细节你直接定就行。

如果你反而希望它多跟你商量、别自己做太多决定，把最后那句授权去掉就行。

### 发出指令前，先扫一眼这五件事

每次要让 Agent 开新卡或改旧卡前，可以快速核对一遍：

- 开新卡时，除了题材名字，也写清楚玩家是什么身份、正碰上什么麻烦。
- 想固定角色的说话方式时，直接给一两句台词当样本，少堆抽象的性格形容词。
- 先定好画面要纯文字阅读还是带数值和选项，不想要的默认面板直接点名去掉。
- 交代清楚做到哪一步算完成，以及多少积分以内的试玩可以直接跑。
- 修改已有卡片时，一条消息只集中解决一个问题。

## 试玩之后怎么改语气、修卡壳与接续进度

卡片聊上两三轮通常看不出毛病，真正的问题往往出在十轮往后，比如角色突然太快示好、台词开始车轱辘话，或者改了一处却把原本写好的段落带坏了。

### 让 Agent 用不同模型和开场白跑十轮实测，并看工作记录

只问一句“你测过了吗”，得到的回答多半是“测过了”，但默认试聊两轮只能确认开场白没坏。一张卡耐不耐玩要跑到十轮以后才见分晓，而且便宜的小模型最容易先露怯。你可以指定用哪个备选开场白、分别拿小模型和高阶模型跑 10 到 20 轮（实际对话会扣积分，Agent 会先报价）。跑完除了听它总结，也可以直接打开卡片文件夹里的 `README.md`。那是 Agent 留在本地的工作记录，里面记着每一版改了什么、为什么放弃某个写法，以及测试抓到的对话证据（这个文件不会上传到服务器）：

> 拿第二个备选开场白，分别用一个便宜的小模型和一个高阶模型各开新对话跑 15 轮。帮我看大概聊到第几轮会开始车轱辘话或者接不下去、问题出在哪儿，把测出来的结果记进 `README.md`，开跑前先跟我说大概要花多少积分。

### 只报你玩到的现象，别替它指定改哪一段

自己试玩觉得不对味时，如果直接下令“把人设第二段砍短一点”，往往治标不治本。你在界面上看到的是结果，真正让角色跑偏的原因常常藏在开场白示范、对话示例或输出格式里。直接把你玩到的现象描述出来，让它去查根因，并要求改完后拿同一组对话跟上一版对比给你看：

> 我刚才自己玩，才聊到第三轮她就主动贴上来表白了，我希望慢热得多，前十轮都还在互相试探。你先查一下是什么地方让她这么快上头，改好之后拿我刚才那几句话重跑一次，跟改之前的回复对照给我看。

### 一个版本只改一件事

把“开场白太长、她太快示好、世界观太薄、顺便把配角名字换掉”塞进同一句话里，Agent 一次改动太多文件，改坏了根本分不清是哪一刀出的问题，也很容易顺手改掉你原本满意的段落。每次只指定修一个毛病，其他它顺带发现的问题先列出来别动：

> 这一版先修她太快上头这件事就好，其他你看到的毛病先列出来别动文件。改完跟我讲你动了哪几个文件、各改了什么。

### 只想听分析、还不要改文件时先讲明

当你问“这张卡是不是改成多路线更好玩？”，Agent 有时分不清你只是在商量，还是已经让它动手改稿，常常问完就直接开始改文件。如果只是想听听利弊，第一句话先让它别动文件：

> 先别改任何文件。你觉得这张卡现在走单线慢热陪伴更稳，还是拆成三个篇章更耐玩？跟我讲两边各自的优缺点就好，等我拿定主意再动手。

### 新开对话窗口，或跟网页编辑器一起改

关掉终端重开一个新会话时，Agent 没有上一次的聊天记忆，只说“继续改昨天那张卡”它就得从头猜。让它先读卡片文件夹里的 `README.md`，就能立刻接上之前的进度：

> 接着改 `cards/night-diner` 这张卡。你先读里面的 `README.md`，跟我对一下上一版改到哪儿了、还剩哪些待办，确认完再往下做。

如果你中途自己开网页编辑器改过文字或世界书，开工前跟它说一声“先从线上把最新版拉下来”；如果你还在网页上边改人设、只想让 Agent 帮你补几条世界书，它也可以用单条世界书命令只更新那几条设定，遇到版本冲突会自动停下，不会把你在网页刚存好的内容覆盖掉。

## 存成正式卡、私下分享与送审公开

试玩卡在最后一次更新满 3 天后就会自动过期，确定要留下这张卡、发链接给朋友玩，或是上架到首页榜单拿积分返点时，再让 Agent 帮你存成正式卡或检查送审条件。

### 存成正式卡与三种可见范围

跟 Agent 说“帮我把这张试玩卡存成正式卡”，卡片就会进到你的“我的卡片”列表里，不再过期。新建正式卡默认的可见范围是**“知道链接的人”**：不会出现在首页榜单和搜索结果里，也不用先送审，只要把链接发给朋友，对方就能直接打开玩最新存档。如果你只想留给自己玩，随时可以让它改成**“仅自己”**。

### 送审上架前的检查

想把卡片设为**“公开”**（排进首页与搜索、积累热度参加日榜、周榜和月榜奖金结算，并在其他玩家来聊时分到积分返点），卡片需要满足三个条件：至少选一个官方的分类或玩法标签、“角色设定”加上“已启用的世界书常驻条目”合计超过 3,000 个有效字（中英文字母与数字均按字符计算，不含标点空白、开场白、对话示例与非常驻条目），以及填好内容分级问卷。送审前可以先让 Agent 全部核对一遍：

> 先别送审，帮我检查这张卡现在能不能公开上架，看有效字数、分类标签和字段有没有缺，把还要补的地方列给我。

卡片公开之后，你依然可以继续让 Agent 修改。后续推送只会更新你自己的草稿（你可以用草稿链接先试玩），线上玩家玩的仍是已经过审的版本，直到你再次送审通过为止；更新送审默认不会打扰玩家，只有你主动要求发更新通知并写上更新说明时，才会在过审后通知收藏卡片与关注你的人（每张卡每 3 天最多通知一次）。

### 积分与安全界线

- 起草、修改文件、本地规则检查、沙箱画面预览、渲染开场白与上传卡片，全部不消耗网站积分。
- 只有“实际发消息跟角色试聊”和“调用模型生成图片”会消耗积分（生图仅使用充值积分），这两个命令都必须带上扣点参数才会执行，Agent 动手前一定会先征得你的同意。
- Agent 只会修改试玩卡与你交给它处理的卡片；除非你开口要求，否则它不会自己替你送审、发更新通知或把卡片改成公开。
