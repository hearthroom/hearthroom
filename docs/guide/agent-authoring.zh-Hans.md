## 能交给 AI Agent 的事

AI Agent 按官方写卡技能工作：先问清楚你要什么，把卡写成文件夹、推成试玩卡，自己检查和试玩，再告诉你哪里还能更好。每一项都附一句可以直接对它说的话。

### 从一个点子写出整张卡

> “写一张修仙文的卡：我是被逐出宗门的废柴，师姐偷偷帮我，要有修为和好感度两个状态，先做成试玩卡。”

只有模糊的想法也可以，它会先陪你把设定、人物、关系和开场白想清楚再动手。

### 修好一张现有的卡

> “导入这张 SillyTavern 卡，告诉我为什么聊三轮就没话说，然后修掉。”

SillyTavern 的 PNG、JSON、CHARX 和魅魔岛三件套都能直接导入。

### 做状态栏、主题或整页界面

> “加一个显示好感度和所在地点的状态栏，渲染开场白给我看。”

需要时它会用开源的 tavern-mmd 技能做界面，导入卡片后渲染出来确认。

### 试玩并找出问题

> “用第二个开场白玩两轮，告诉我玩家会在哪里失去兴趣。”

### 上架前的检查

> “检查这张卡能不能送审，列出还要修的地方。”

## AI Agent 怎么写卡

1. **写成文件夹**：长文是 Markdown 文件，世界书、规则和图片各有自己的文件，你也能打开来看或自己改。
2. **推成试玩卡**：只有你看得到，最后一次更新后 3 天过期，同时最多 5 张。
3. **检查与渲染**：按平台规则检查字数与内容，把开场白套上规则渲染出来，确认状态栏和版面正确。
4. **试玩**：真的跟角色聊一轮，看回复撑不撑得住、玩家接不接得下去。
5. **修改**：按结果改，再推、再试，直到你满意。
6. **留下来**：满意之后存成正式的私人卡，出现在“我的卡片”。送审和公开由你在网站上决定。

## 让 AI Agent 写得更好

- **说清楚想要的玩法**：陪伴、剧情、游戏或角色生成器，写法完全不同。
- **给它素材**：二创就说清楚是哪部作品的哪个角色，再加上你的设定和喜欢的卡。
- **要它试玩**：只写不玩的卡，最常见的问题是聊几轮就没戏；请它先玩两轮再交给你。
- **一次改一件事**：“开场白太长、她太快示好”比“整体再好一点”有效。
- **看它的报告**：每次推送后的检查结果和渲染画面，比它自己的总结可靠。

## 点数与界线

- 起草、推送、检查和渲染都不花点数。
- 试玩一轮会用到你的点数，AI Agent 会先问过你。
- 它只动试玩卡和你自己的私人卡，不会替你送审或公开。
