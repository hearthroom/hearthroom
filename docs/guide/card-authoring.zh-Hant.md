# 寫卡指南

本指南說明角色卡的組成、兩種聊天頁的差異、規則與腳本的寫法，以及從其他平台匯入時的注意事項。

## 卡片的組成

| 欄位 | 說明 |
|---|---|
| 名稱、直式背景、橫式背景（選填） | 直圖也會用於 PNG 匯出與聊天頭像。 |
| 簡介 | 榜單卡片上的摘要。 |
| 人設 | 角色的身分、說話方式與世界觀。 |
| 開場白 | 對話的第一則訊息，可設定多個備選。 |
| 世界書 | 依關鍵詞觸發的補充設定。 |
| 規則 | 正規表示式規則，將回覆中的特定文字轉換為版面、狀態欄或按鈕。 |
| 聊天頁 | 卡片使用的聊天頁：沙箱或傳統。新卡預設為沙箱。 |

卡片儲存後，編輯頁右側的「對話測試」面板即可直接對話。在寬螢幕上，拖曳面板左緣的把手可調整預覽寬度。

## 聊天頁

兩種聊天頁使用相同的介面（頁首、訊息、輸入區、面板），差異在於卡片的規則與腳本在何處執行。

### 沙箱

卡片的畫面與腳本在獨立於站台的隔離頁面中執行。

- 樣式與腳本可修改整個聊天畫面。
- 腳本無法存取玩家的登入狀態。
- 送出、重新生成等會消耗點數的動作，只回應玩家本人的點擊。

### 傳統

規則直接套用在站台的聊天頁上。僅在既有卡片於沙箱中運作異常時使用。

### 切換

在編輯頁「基本」分區的「聊天頁」選項切換。既有卡片切到沙箱後，開啟「對話測試」確認功能欄、開場白內的面板、浮動按鈕、選單與各面板的顯示是否與先前一致。多數卡片不需修改；若有效果缺失，參考「從傳統頁遷移」。

## 規則

每條規則由「尋找」與「取代」組成。回覆文字在顯示前依序套用所有規則。

### 尋找

固定字串（如 `《狀態欄》`）或正規表示式（如 `/<status>([\s\S]*?)<\/status>/g`）。使用正規表示式時，取代內容中的 `$1`、`$2` 對應擷取群組。

### 取代

任意 HTML，可包含 `<style>` 與 `<script>`。所有規則的 `<style>` 合併為一份樣式表套用；每段 `<script>` 每張卡執行一次。

### 功能欄

規則編輯器中的「功能欄」是固定顯示在訊息列表上方的內容，只對玩家顯示，不會送給模型。一般做法是在此放置觸發詞（如 `【狀態欄】【美化】`），再由規則展開為實際的面板。

### 巨集

| 巨集 | 值 |
|---|---|
| `{{user}}` | 玩家的稱呼 |
| `{{char}}` | 角色名稱 |

### 限制

- 單條規則上限 128 KB。
- 整份規則超過上限時，編輯器會顯示超出的量。

規則編輯器的「測試」欄可貼入範例回覆，即時檢視套用結果。

## 沙箱作者 API

沙箱頁提供固定的節點屬性與 `sdk` 物件，與魅魔島（MMD）新版沙箱相同，同一份腳本可在兩個平台執行。

### 節點

以 `data-chat` 屬性選取節點，不要依賴 class 名稱。

| 選擇器 | 說明 |
|---|---|
| `[data-chat="root"]` | 聊天畫面的根節點。`data-theme` 為 `dark`／`light`；`data-composer` 表示輸入區是否顯示。 |
| `[data-chat="message"]` | 一則訊息。`data-from` 為 `ai`／`user`；`data-state` 為 `pending`／`streaming`／`done`；`data-msg-id` 為伺服器端的訊息 ID。 |
| `[data-chat="message-body"]` | 訊息正文（套用規則後的 HTML）。 |
| `[data-slot="statusbar"]` | 功能欄。 |
| `[data-chat="author-stage"]` | 作者舞台。`sdk.stage.open('content')` 覆蓋訊息區，`open('full')` 覆蓋整頁。 |
| `[data-chat="input"]` | 輸入框。 |
| `[data-chat="composer"]` | 輸入區。 |

### CSS 變數

顏色與尺寸由 `--chat-*` 變數定義（如 `--chat-bg`、`--chat-text`、`--chat-accent`、`--chat-bubble-ai-bg`）。在根節點覆寫即可整體換色。

### sdk

| 方法 | 說明 |
|---|---|
| `sdk.input.get()` / `set(text)` / `add(text)` / `insert(text)` / `clear()` / `focus()` / `blur()` / `getCursor()` / `setCursor(pos)` | 讀寫輸入框。 |
| `sdk.composer.show()` / `hide()` / `visible()` | 顯示或隱藏輸入區。 |
| `sdk.message.send(text)` | 以玩家身分送出訊息。若不是在玩家的點擊事件中呼叫，會先向玩家確認。 |
| `sdk.message.edit(id, text)` | 改寫指定訊息並重送。同樣需玩家確認。 |
| `sdk.save.get(key)` / `set(key, value)` / `remove(key)` / `keys()` | 存檔。每張卡每位玩家最多 10 個 key；key 限英數、`_`、`-`；單值上限 64 KB；跨裝置保留。 |
| `sdk.cache.get(key)` / `set(key, value)` / `remove(key)` | 暫存。僅在本次頁面載入期間有效。 |
| `sdk.stage.open(mode)` / `close()` / `el()` / `visible()` | 作者舞台。 |
| `sdk.role.get()` | 角色名稱與頭像。 |
| `sdk.user.get()` | 玩家稱呼與頭像。 |
| `sdk.on(event, handler)` | 訂閱事件。 |
| `sdk.debug.log(...args)` | 寫入除錯面板。在網址加上 `?sdkDebug=1` 可顯示面板。 |

### 事件

| 事件 | 時機 |
|---|---|
| `ready` | 既有訊息全部掛載完成後觸發一次。 |
| `message:new` | 新訊息建立。 |
| `message:mount` | 訊息節點掛載到畫面。 |
| `message:stream` | 串流輸出更新。 |
| `message:done` | 訊息完成。 |
| `message:unmount` | 訊息節點移除。 |
| `input:change` | 輸入框內容變更。 |
| `conversation:switch` | 切換對話。 |
| `theme:change` | 深淺色切換。 |
| `back` | 玩家按下返回。 |
| `stage:close` | 作者舞台關閉。 |
| `dispose` | 頁面即將卸載。 |

### 執行規則

- 開頁時，每則既有訊息依序觸發 `message:new`、`message:mount`、`message:done`，最後觸發 `ready`。
- 在訊息掛載後才訂閱 `message:mount` 或 `message:done` 的處理函式，會收到已掛載訊息的補發。
- 事件處理函式內的 `document.querySelector` 只搜尋該則訊息；處理函式外為一般的 `document`。
- 腳本無法對外部網址發出請求。外部 `<script src="https://…">`、圖片與字型可正常載入。

### 錯誤碼

| 錯誤碼 | 說明 |
|---|---|
| `UNAUTHORIZED` | 玩家拒絕了需要確認的操作。 |
| `RATE_LIMITED` | 呼叫過於頻繁。 |
| `INVALID_ARGS` | 參數不合法。 |
| `HOST_DENIED` | 宿主頁拒絕此操作。 |
| `BUSY` | 正在生成中。 |
| `NOT_SUPPORTED` | 目前環境不支援此功能。 |

## 從傳統頁遷移

傳統頁的規則直接套用在站台的聊天頁上，作者常用的選擇器為 `.mes`（訊息）、`.mes_text`（正文）、`.mes.Ai`／`.mes.User`（發言者）、`#msglistview`（列表）、`.chat-scope-box`（對話區）。這些選擇器在沙箱頁中同樣存在。

- 只使用樣式與文字取代的卡片不需修改。
- 以 `<img onerror="…">` 啟動腳本的做法在沙箱中可用；放在功能欄或開場白中的引擎片段都會被執行。
- 直接讀寫站台頁面其他區域的腳本，改用 `sdk`。
- `localStorage` 在沙箱中可用，但資料只存在卡片自己的來源下；需要跨裝置保留時改用 `sdk.save.*`。

## 匯入

| 來源 | 方式 |
|---|---|
| SillyTavern | 將 PNG 或 JSON 角色卡拖入「基本」分區。人設、開場白、世界書與正則腳本自動填入；PNG 內的立繪用作直式背景；另附主背景時優先採用主背景。 |
| 魅魔島（MMD）三件套 | 分別匯入規則檔（含 `chatVersion`）、開場白與人設。標記為新版沙箱的規則檔會自動選取沙箱聊天頁。 |

匯入後在「對話測試」確認顯示無誤，再儲存並發布。

## 疑難排解

| 現象 | 處理 |
|---|---|
| 開卡後畫面空白十餘秒 | 首次載入沙箱頁的資源較慢，之後由快取加速。超過 20 秒仍空白時會出現提示，重新整理即可。 |
| 卡片的導覽或遮罩覆蓋畫面、無法捲動 | 這是卡片自帶的教學層，按它的「跳過」。 |
| 腳本沒有反應 | 在網址加上 `?sdkDebug=1` 開啟除錯面板，檢視腳本錯誤與 `sdk.debug.log` 的輸出。 |
| 存檔失敗 | 確認 key 只含英數、`_`、`-`，單值未超過 64 KB，且該卡的 key 數未達 10 個。 |
