# HearthRoom 社群審核試作

2026-09-20。試作驗證完成後，owner 已授權發布。實際部署與正式讀回結果另記於發布紀錄；本功能不會自動提升任何現有帳號權限。

## 使用流程

HearthRoom 首頁與手機帳號選單統一使用「社群管理」入口，顯示目前帳號可處理的待辦總數／紅點。`/review` 是同一個工作台，分成卡片審核（首頁）、處置複核（`/review/cases`）、作品管理（`/review/cards`）、處理紀錄（`/review/history`）；卡片審核詳情仍在工作台內。卡片審核與處置複核各顯示自己的待辦數。舊 `/review/manage` 書籤轉到處置複核，保留語言、查詢與錨點。各功能使用同一份審核員資格，管理員專屬操作另驗權限。切換功能、登入身分或審核權限時清除舊選取、理由及未完成確認。

| 動作 | 生效方式 | 結果 |
| --- | --- | --- |
| 品質退榜 | 兩位不同審核員同意 | 從榜單、搜尋、推薦及公開作者列表退出；直接連結與公開遊玩保留 |
| 嚴重問題暫停 | 第一位立案立即暫停，第二位複核 | 停止本站公開頁、相關 API 與 immutable hosting 的公開遊玩授權；不刪作者原稿 |
| 提出異議 | 第二位提出異議 | 嚴重案件繼續暫停，由未參與的管理員裁決；品質案保留原狀 |
| 恢復曝光／公開 | 兩位不同審核員同意 | 恢復對應能力；公開恢復只放行案件所審的版本 |
| 改社群標籤 | 管理員直接操作並填理由 | 改社群呈現，不改作者原稿；來源同步不能覆蓋修正 |
| 補償曝光時間 | 管理員選日／週／月榜及時數 | 延長所選榜的資格窗口，不增加熱度、不改原始發布日；每次最多 720 小時 |

審核員不能處置自己的作品、重複投票或讀取未經年齡驗證的成人案件。管理員不能裁決自己已參與的爭議案。理由必填；提案、標籤與補償附操作識別，重試不重複生效。

## 版本與稽核

作品的公開審核結果與社群傳播限制分開存。限制以來源作品為鍵，撤銷登記再登記也不會消失。嚴重暫停立即使已核准的 hosting 版本回覆 revoked；新的內容審核通過也不能自行解除限制。

恢復公開時只放行案件版本，其餘先前核准版本保留停用紀錄。恢復案等待中若核准了更新的版本，舊恢復案自動結案，需對最新版重新立案。投票及裁決交易再原子核對版本，防止並行更新繞過檢查。誤判裁決駁回則撤銷該暫停案的版本限制。

案件保存立案時的公開介紹、標籤、開場內容及卡號／版本，第二位可在公開頁已暫停後查看。僅保留公開內容；作者私有指令與 Lorebook 等完整送審快照仍依既有契約在原審核結束後刪除。本版沒有新增能取回已刪私有快照的能力。舊登記資料若沒有獨立開場欄位，顯示既有公開搜尋文字。

案件、票決、裁決、標籤及補償均有持久紀錄；列表與工作台不回傳內部成員 ID。新增公開傳播快取 revision，處置後新請求不命中舊的內部邊緣快取；對外回應使用 no-store，成人／作者預覽仍保留 private。

## 權限與部署界線

`reviewers.role` 分 reviewer、manager、owner。既有審核員遷移後仍是 reviewer，不自動升權。這次提供角色檢查與管理員操作；招募、授權及撤銷的管理介面尚未包含在試作。首次 manager／owner 指派需另有明確授權及可稽核流程，不能直接把所有 reviewer 升級。

本版沒有 LunaTalk 整合工作。沿用現有來源識別及相容 API，沒有替其他產品建立管理後台。

部署前需要 migration `0025_community_moderation.sql`，再部署與之匹配的 Worker／前端。正式上線須遵守倉庫部署流程、完整測試、授權和正式站讀回。本機驗證不能替代實際 provider callback、正式權限及正式 D1 遷移的驗證。

## HTTP／MCP 決策

新增 `/v1/moderation/*` 是 HearthRoom 站務人員流程，使用社群成員／reviewer 權限，不適用目前面向作者的 provider MCP 與 Moonloom 創作工具。本次不向 AI 創作客戶端新增停權能力。公開遊玩仍透過既有 hosting decision，HTTP／MCP 的 provider hosting 授權均讀同一份決策，未增加旁路。

## 可觀測性

`hearthroom_moderation_requests_total` 為持久累計 counter，標籤僅 `operation`（read、propose、vote、resolve、tags、compensation、staff）及 `outcome`（success、denied、error）。路由回應完成後依 HTTP 狀態記錄；記錄失敗只輸出固定訊息，不含成員、案件、內容或 token。`/metrics` 可讀回；例如 `sum by (operation, outcome) (rate(hearthroom_moderation_requests_total[5m]))`。正式監控抓取與告警尚未部署。

2026-09-20 導覽統整：僅調整既有前端工作台、五語名稱與待辦呈現，沒有新增 HTTP／MCP 能力或改變權限。可觀測性沿用既有 API 計數與部署資源讀回，不新增前端指標。
